# PixelForge community principles

PixelForge is intended to become a free creative community, not only a wallpaper player.

## For creators

- Creators keep credit and choose the license for their work.
- Do not upload artwork, music, fonts, videos, or code that you do not have permission to share.
- Wallpaper packages should include creator name, source links, license, and required third-party notices.
- Tools should be usable without a subscription or mandatory account.

## For users

- Downloads should identify what they contain before installation.
- Community packages should be inspectable and removable.
- The application should clearly distinguish local files from downloaded content.
- Network access should be visible and optional wherever possible.

## For maintainers

- Keep the core application free and open source.
- Prefer permissive dependencies and document their licenses.
- Do not copy proprietary Wallpaper Engine code, assets, or formats.
- Review security reports privately before public disclosure when appropriate.
- Make performance and battery behavior first-class features.

## Sharing model

The planned sharing format is a portable PixelForge package containing metadata, preview images, wallpaper assets, and license information. Executable code and scripts should be disabled by default and require explicit user approval after inspection.

## Donations

Donations and sponsorships may support development, build infrastructure, accessibility, documentation, and community moderation. Donations will not unlock essential features or create a subscription requirement.
